# 🎮 GameDev | AnanthaKrishnan SB - Pixel UI Portfolio

A faithful, pixel-perfect, responsive replica of the **Minecraft Pixel-UI Game Developer Portfolio** design reference. Built with pure HTML5, CSS3, and Vanilla JavaScript with zero external runtime dependencies.

---

## ✨ Features & Visual Highlights (Matching Reference Style)

### 1. 🟪 Pixel-Art Aesthetic & 3D Beveled UI
- **Stepped Pixel Borders**: Every card features authentic stepped pixel borders (`#bba6f7`), crisp 2px outlines, and smooth glass surfaces (`rgba(255, 255, 255, 0.95)`).
- **3D Minecraft Beveled Buttons**:
  - `View Projects →`: Vibrant purple button (`#7c3aed`) with a 5px darker bottom 3D bevel (`#4c1d95`), gamepad icon, and pixel arrow.
  - `About Me`: Clean white 3D beveled button with user icon.
  - `Home` nav item: 3D purple bevel button with pixel home icon.
  - Pressing buttons pushes them down with realistic tactile depth!
- **Minecraft Typography**:
  - Main headline features the **Silkscreen Pixel Font** in vibrant purple: `AnanthaKrishnan SB`.
  - Body text uses clean, crisp `Plus Jakarta Sans` for maximum readability.
- **Ambient Lilac Pixel Atmosphere**:
  - Corner pixel clusters (sizes 8–16px) floating in the four corners and edges of the viewport.
  - Smooth 60FPS drifting ambient pixel dust canvas.
